# Demo Artifacts

This repository is a public demonstration of the
[vendor-admx-archive](https://github.com/david-r-cushman/vendor-admx-archive)
workflow.

All vendor names, product names, policy settings, ADMX files, ADML files, and
ZIP archives in this repository are fictional and self-authored. They do not
represent a real vendor, product, download, or policy recommendation.

The example releases use these intentionally simple names:

- Vendor: Example Vendor
- Product: Example Administrative Templates
- Policy namespace: `Example.Policy`

The ZIP file in each release's `source/` directory is the preserved example
distribution. The matching content under `extracted/` is an inspection copy
provided so that changes between releases are easy to view in GitHub.

All demonstration artifacts under `versions/` are licensed under the
repository's [MIT License](LICENSE), along with the repository's scripts,
tests, workflow, and documentation.
